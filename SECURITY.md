# Security policy

Do not store passwords, API keys, access tokens, private keys, personal data or confidential project text in issues or in a public `project.ithz` archive.

For a suspected vulnerability, contact the repository owner privately through the contact channel published on [ithz.dev](https://ithz.dev/) and include only the minimum reproducible information. Rotate any credential that may already have been exposed.

The MCP36.4 canary is defensive evidence. Its verdict does not authorize external actions, and provider credentials remain outside this repository and its release assets.
